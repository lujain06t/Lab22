# AI381 Lab 2 - Customer Churn API

A FastAPI service that serves the Lab 1 logistic-regression churn model. It accepts a customer's account features and returns a churn probability and a 0/1 prediction.

## Requirements

- Python 3.11 or newer
- Docker Desktop (WSL 2 backend on Windows)

## Run everything with one command

After cloning this repository and opening a terminal in its folder, run:

```bash
python -m pip install -r requirements.txt && python -m src.train.train && docker build -t ai381-churn . && docker run --rm -p 8000:8000 ai381-churn
```

This single command installs the libraries, trains and saves `model.joblib`, builds the Docker image, then starts the service. On Windows PowerShell, paste it as one line. Leave the terminal open while using the API.

## Endpoints

- `GET /health` - returns `{"status":"ok"}` when the model is available.
- `POST /predict` - validates the customer input and returns `churn_probability` and `predicted_churn`.
- `GET /docs` - interactive API page generated by FastAPI.

Example request body:

```json
{
  "tenure_months": 12,
  "monthly_charges": 70.5,
  "support_calls": 2,
  "contract": "month-to-month",
  "internet_service": "fiber"
}
```

Example PowerShell request:

```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8000/predict -ContentType 'application/json' -InFile .\sample_request.json
```

The allowed `contract` values are `month-to-month`, `one-year`, and `two-year`. The allowed `internet_service` values are `dsl`, `fiber`, and `none`. A probability closer to 1 means the model estimates a higher chance of churn; it is a model estimate, not a guarantee.

## Train with Lab 1's version 2 dataset

The API keeps the same input name `monthly_charges`. The training script automatically maps the `monthly_fee` name in `churn_v2.csv` to it:

```bash
python -m src.train.train --data data/churn_v2.csv
```

Then rebuild the image using the one-command instructions above (omit the install step if already installed).

## Tests

Train first, then run:

```bash
python -m pytest -q
```

The tests cover model loading, both endpoints, the response contract, invalid/missing inputs, edge cases, and repeatable predictions.

## Model and dataset

The training code follows the Lab 1 starter notebook: numeric features are standardized, categorical features are one-hot encoded, and logistic regression predicts `churn`. The fitted preprocessing and classifier are saved together in `model.joblib`.
